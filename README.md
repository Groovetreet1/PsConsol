# PS5Consol

A modern, dependency-free landing page concept for a next-gen PS5 console showcase.

![Status](https://img.shields.io/badge/status-live%20concept-43e7ff)
![HTML](https://img.shields.io/badge/HTML5-single%20page-2f7bff)
![No build](https://img.shields.io/badge/build-none-8a5cff)

## ✨ Highlights

- **Cinematic hero** with a pure-CSS PS5 console, floating glass chips and a 3D tilt effect
- **Animated bento features** — SSD speed meter, haptic pulses, ray sweeps and a 3D-audio equalizer
- **DualSense-style controller** drawn entirely in CSS
- **Horizontal game showcase** with snap scrolling and arrow controls
- **Tech specs table**, newsletter CTA with validation and toast feedback
- Fully **responsive** (desktop / tablet / mobile) with a mobile menu
- **Accessible**: skip link, focus states, `aria` attributes and `prefers-reduced-motion` support
- Zero dependencies, zero build step

## 🚀 Run locally

Just open `index.html` in a browser.

Or serve it with any static server:

```bash
npx serve .
# or
python -m http.server 8080
```

Then visit `http://localhost:8080`.
